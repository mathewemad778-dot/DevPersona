# DevPersona

DevPersona is a small web project I built for fun. The idea is simple: answer a few questions and find out what kind of developer personality you have.

## What this project does?

* Gives users a short developer personality quiz
* Shows a unique personality type based on the answers
* Displays strengths and a small personality breakdown
* Lets users restart the test and try different answers

## Features.

* Clean and simple UI
* Progress bar while answering questions
* Animated transitions between sections
* Result screen with personality description
* Share buttons for social platforms

## Tech used.

* HTML
* Tailwind CSS
* JavaScript
* Font Awesome icons

## Why I made this?

I wanted to build something small but interactive. The goal was to practice frontend structure, UI design, and basic JavaScript logic while making something fun for developers.

## Notes!

This project is just for fun and learning purposes. The personality results are not meant to be taken too seriously.
